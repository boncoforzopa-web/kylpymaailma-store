# Kylpymaailma – kylpymaailma.com on Vercel

Finnish-language storefront for hijabs, khimars and abayas. Server-rendered Liquid theme (`theme/`)
on a small Shopify-compatible engine (`lib/engine.js`), one Vercel function, Stripe for payments.

| Path | What |
|---|---|
| `theme/` | Theme: sections, snippets, layouts, `assets/km.css` (design) on top of `assets/tw.css` (base components). |
| `theme/config/settings_data.json` | Brand and **company details** (name, address, Y-tunnus, e-mail). Legal pages show a yellow "Tieto puuttuu" note for anything left empty. |
| `theme/templates/index.json` | Homepage sections and their texts. |
| `data/products.json`, `collections.json`, `collection-order.json` | Catalogue. Generated by `scripts/catalog/build_catalog.py` – edit the CSVs / Finnish texts there and re-run. |
| `data/pages.json`, `menus.json` | Pages (terms, returns, privacy, …) and menus. |
| `public/images/` | Product images (WebP, several widths), generated from `scripts/catalog/source-images/`. |
| `lib/brand.js` | Shop name, domain, country, VAT rate (25.5 %), delivery estimate, URL paths. |
| `lib/` | Router, cart, checkout (Stripe Payment Element), e-mails, forms, stock, Google feed, admin (`/admin`). |
| `api/index.js` | The single Vercel function. |

## Updating the catalogue

1. Edit `scripts/catalog/products.csv` / `variants.csv` (prices, stock, new variants).
2. For a new product add its Finnish title/description to `FI` in `scripts/catalog/build_catalog.py`
   and its photo as `scripts/catalog/source-images/<handle>.jpg`.
3. `python3 scripts/catalog/build_catalog.py` (needs Pillow), commit, push.

Stock sold through the shop is tracked live in Redis (see below); the CSV is the starting stock.

## URLs

`/products/<handle>`, `/collections/<handle>`, `/collections/all/<colour>` (colour filter), `/pages/<handle>`,
`/cart`, `/checkout`, `/tilaus` (order tracking), `/sitemap.xml`, `/feeds/google.xml` (Merchant Center feed).

## Local preview

`npm install && node scripts/build.js && node scripts/dev.js` → http://localhost:3000
E-mail previews: `node scripts/email-previews.js email-previews`

## Environment variables

See `.env.example`. Without Stripe keys the shop runs, but the checkout shows "payment not available".
